# MOR Sports Performance: Find your assessment

A short set of questions that points athletes, parents, clinicians, and staff to the right
Sports Performance assessment, with prices, what to expect, and Mindbody booking links.

Live page: https://morsportsperformance.github.io/Services/

`index.html` is the page; `figs.js` holds the 3D figures and loads in the background.
Both are built files: edit the source, rebuild, and copy them here.
